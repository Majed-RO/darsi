# Darsi (دَرْسي)

An Arabic, mobile-first learning and practice platform for students in Palestine. It starts with math in grade 7 and is meant to cover more subjects and grades.

> **Status:** planning. Implementation hasn't started yet.

## Documentation

- [docs/PLAN.md](docs/PLAN.md): background, decisions log, open questions and planning status.
- [docs/plan/](docs/plan/): one document per planning step (scope, architecture, testing, workflow, implementation plan).
- [docs/runbooks/](docs/runbooks/): procedures for rare operations.
